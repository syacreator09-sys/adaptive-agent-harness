# Domain packs

AAH's universal contract is `REQUEST → SPEC → PRODUCE → VERIFY → FINDINGS → FIX → RE-VERIFY → FINAL GATE`.

The `code`, `content`, `research`, and `operations` domain packs change agent identities, tools and evidence expectations without changing that contract. Code is the most complete V1 implementation; other packs reuse the same runtime and can be extended with local provider skills/MCP tools.
